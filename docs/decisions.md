# 決策紀錄

PRD 沒有規範、或規範後在實作中發現需要另行判斷的事項。每則記錄**為什麼這樣決定**
與當時的實證依據，讓後續接手的人（或 AI 助理）不必重新踩一次坑，也能在條件改變時
知道該推翻哪一條。

格式：決策 → 背景 → 實證 → 結論 → 影響範圍。

---

## D-01　三張報表的期間語意不同

**背景**　FinMind 的財報 dataset 以長表回傳，未說明各表的期間語意。原實作一律當
單季值處理，四季相加得年度值。

**實證**（2026-09-15，以 2330 FY2024 對照公告數）

| dataset | Q1 → Q4 | 結論 |
|---|---|---|
| 損益表 EPS | 8.70 / 9.56 / 12.55 / 14.45 | 單季值，四季相加 45.26（公告 45.25）|
| 現金流量表 營業活動 | 436.3B → 814.0B → 1,206.0B → 1,826.2B | 逐季遞增，Q4 即全年（公告 1,826.2B）|
| 資產負債表 權益 | 3,665.7B → 4,323.6B | 期末存量 |

**結論**　三者分別為 `quarterly` / `cumulative_ytd` / `instant`，寫在
`config/finmind_fields.yaml` 的 `period_semantics`。

**影響**　舊作法把現金流量表四季相加，營運現金流與資本支出高估約 2.5 倍，
自由現金流因子完全失真。`tests/test_finmind_periods.py` 以上述實際數列固定行為。

## D-02　FinMind 不回傳餘額為零的會計科目

**背景**　部分公司的資產負債表完全沒有借款科目。無法分辨是「確實無長期負債」
還是「資料缺漏」—— 前者該得分（負債比為 0），後者該標 N/A。

**結論**（需求方 2026-09-15 確認）　該年度期末資產負債表本身有回傳、卻無任何
借款科目時，認定長期借款為 0 並照常評分；整年無期末資產負債表才標 N/A。
此認定會寫入 snapshot 的 provenance note，不會偽裝成實際查得的值。

**影響**　大立光、信驊、創意等確實無長期借款的公司不再被誤判為缺漏。
這是本專案唯一一處「以推論補值」的例外，因為它可由資料結構本身推得，
而非猜測數值。

## D-03　董監持股改用 open data，並修正兩個會算錯的陷阱

**背景**　FinMind 不提供董監持股。原判定為「需人工匯出 CSV」，**該判定是錯的** ——
當時只測了被 IP 封鎖的 MOPS 與 TWSE，沒有查 TPEx 的 openapi 目錄。

**實證**　資料在公開 open data 就有，免金鑰：

| 市場 | 端點 |
|---|---|
| 上市 | `https://openapi.twse.com.tw/v1/opendata/t187ap11_L` |
| 上櫃 | `https://www.tpex.org.tw/openapi/v1/mopsfin_t187ap11_O` |

實測 17,472 列、887 家上櫃公司後發現兩個陷阱：

1. **它是「內部人」全表，不是董監表。** 職稱含總經理、副總經理、協理、經理、
   會計／財務部門主管、大股東、其他。只排除獨立董事並不夠 —— 須以
   「職稱含董事或監察人」白名單挑選，再排除獨立董事。
2. **法人董事佔多席時，同一法人持股會每席重複列示。** 環球晶（6488）的中美矽晶
   223,007,864 股佔兩席、列兩次，直接加總會超過其發行股數。
   **887 家中有 380 家（43%）有此情形**，不是邊緣案例。

**結論**　以（姓名, 目前持股, 設質股數）去重；無姓名欄時不去重（避免把兩個不同
的人誤併）。持股比例的分母（發行股數）此表未提供，由 FinMind
`NumberOfSharesIssued` 注入。

**驗證**　信驊 20.90%／質押 4.95%、環球晶 47.17%／0%、群聯 13.36%／7.79%，
與原始資料手算逐檔吻合。

## D-04　ROIC 計算式

**背景**　PRD §8.9 只寫「ROIC」，未定義計算式。

**結論**（需求方 2026-09-15 指定）

```
ROIC        = 稅後營業利益 ÷（股東權益 ＋ 有息負債）   皆取期末值
稅後營業利益 = 年度營業利益 × (1 − 有效稅率)
有效稅率     = 年度所得稅費用 ÷ 年度稅前淨利          同一年度
有息負債     = 期末 短期借款 ＋ 長期借款 ＋ 應付公司債
```

實作時另定兩件 PRD 未涵蓋的事：

- **稅前淨利 ≤0 的年度沒有可導出的有效稅率**，該公司整項標 N/A，不以推估稅率補齊。
  前 50 檔中 4 檔因此為 N/A。
- **有息負債不含一年內到期長期負債與租賃負債**（FinMind 無此科目），
  故分母可能低估、ROIC 略為高估。

**驗證**　2330 五年 20.2／26.2／17.9／20.9／25.6%，2454 為 19.6／24.8／17.0／22.6／21.4%。

## D-05　股息支付率的分子分母期間不一致

**結論**（需求方 2026-09-15 確認維持現狀）

```
TTM Payout Ratio = 最新完整年度現金股利 ÷ TTM EPS
```

分子年度值、分母最近四季滾動值，期間刻意不對齊：PRD §8.4 本就把這項定義成 TTM
指標，而股利是一年一議的年度決策，沒有對應的 TTM 分子。

**已知偏誤**　EPS 快速成長的公司分母跑在分子前面，支付率被系統性低估、偏向落在
`<50%` 的滿分區間。2330 為 19.0 ÷ 86.28 = 22.0% → 2 分。
**日後與人工 StockBoss 評分表對齊時，這是第一個該檢查的地方。**

邊界：TTM EPS <0 → 比率設 0，由「TTM EPS<0」規則給 0 分（與「配息率 0%」是不同的
命中規則）；TTM EPS =0 → 比率無定義，標 N/A 而非視為 0%。

## D-06　Interest Coverage 為重建值

**背景**　PRD §8.7 規定「直接沿用 StockBoss 值」，但 FinMind 無此欄位。

**結論**（需求方 2026-09-15 確認接受）　改以 `TTM 營業利益 ÷ |TTM 利息費用|` 重建。
營業利益取自損益表單季值、利息費用取自現金流量表累計值，各自依 D-01 的期間語意
還原 TTM。

**影響**　此為與 PRD 的實質偏離，分數無法與人工 StockBoss 評分表逐項對齊。
金融業無營業利益科目，該項 N/A。

## D-07　「市值前 N」母體在免費層級無法成立

**實證**　不帶 `data_id` 的全市場查詢一律回 HTTP 400。三種層級實測：

| 層級 | 全市場查詢 | 訊息 |
|---|---|---|
| 匿名 | ❌ | `Your level is free.` |
| 註冊 token | ❌ | `Your level is register.` |
| 贊助（Sponsor） | 未測（需付費） | — |

**註冊 token 只提高每小時配額，不解鎖全市場查詢。**

**結論**　兩條路徑，皆不產生推測出來的市值：有 Sponsor token 走全市場排名；
否則以 `--stocks-file` 指定候選母體，程式仍逐檔以 `收盤價 × 發行股數` 實測市值。
**排名只在池內成立**，執行時會印出警告。

**收斂性觀察**　候選池由 103 檔擴為 234 檔時，新增的 131 檔只有 3 檔擠進前 50
（致茂市值第 22 名、環球晶第 43、景碩第 48），前 50 市值下緣由 0.374 兆升為 0.386 兆。
邊際效益在收斂，但**收斂不等於完備** —— 非全市場掃描就無法證明池外沒有更大的公司。

## D-08　證交所對機房 IP 封鎖

**實證**　`openapi.twse.com.tw`、`mops.twse.com.tw` 回 800 bytes 的
「因為安全性考量，您所執行的頁面無法呈現」。測試四種 User-Agent（curl／Chrome／
python-requests／空值）與補上 Referer、Accept-Language 皆相同，回應無 Server 與
CDN 標記 → **認來源 IP，不認標頭**。同一 IP 打櫃買中心正常，故非政府網站全面阻擋。

**須與另一種阻擋區分**：執行環境自己的 egress 白名單會在 TLS 隧道階段就拒絕
（`CONNECT tunnel failed, response 403`），那是可以在環境設定裡開通的，兩者症狀不同。

**結論**　從一般網路環境執行即可；或手動下載後以 `--director-holdings` 餵檔。
**不得以輪換 IP、住宅代理或偽裝指紋規避** —— 那是規避對方刻意設置的存取控制，
違反使用條款，本專案不提供這類手段。
