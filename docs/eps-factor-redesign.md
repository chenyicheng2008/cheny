# EPS 穩定成長因子改版提案

**狀態：提案中，未定案。** 產線仍使用 `src/twfactor/scoring/factors.py` 的
`score_eps`（PRD §8.1 明線規則）。候選實作在 `scripts/eps_score.py`，
與資料來源解耦，可直接餵本機 CSV 試跑。

本文記錄為什麼認為現行規則需要改、候選公式怎麼來的、以及還沒決定的兩件事。

---

## 一、現行規則的三個結構性問題

現行規則以 4 次 YoY 年減幅分級（≤5% 可接受、>12% 大幅衰退），再加逐年成長加分。
以市值前 50 檔的真實 EPS 實測，發現三個問題。

### 1. 加總結構讓「穩定但停滯」拿滿分

| | EPS 五年 | 趨勢成長率 | 現行分數 |
|---|---|---|---|
| 中華電 2412 | 4.61 → 4.99 | **+1.8%** | **2.0（滿分）** |
| 第一金 2892 | 1.52 → 1.87 | +5.8% | 2.0（滿分）|
| 台灣大 3045 | 3.90 → 4.77 | +5.7% | 2.0（滿分）|
| 奇鋐 3017 | 8.21 → 49.17 | **+51.7%** | 2.0（滿分）|

中華電成長 1.8%（跑輸通膨）與奇鋐成長 51.7% 同為滿分。
這個因子叫「穩定**成長**」，不是「穩定」。

### 2. 明線門檻誤殺成長股，且極不穩健

台積電趨勢 25.3%、R² 0.83、最大回撤僅 17%，只因 2023 年跌 17.5%（跨過 12% 那條線）
掉到 0.5 分。緯穎趨勢 47.3%、R² 0.85 同樣 0.5 分。

**穩健性實測**：對 EPS 各年做 ±3% 隨機擾動，每檔 200 次：

| | 平均漂移 | 最大漂移 | 漂移 >0.1 分的檔數 |
|---|---|---|---|
| 現行規則 | 0.0805 | **0.790** | 10 / 46 |
| 候選公式 | **0.0295** | **0.121** | 5 / 46 |

財報數字差 3%（或改用歸母淨利而非合併淨利），現行規則的分數可能跳動 0.79 分。

### 3. 「穩定」單獨計分會獎勵「穩定地衰退」

南亞 1303 的 R² = 0.85（趨勢非常明確）但趨勢是 **−55.2%**。
任何把穩定度單獨加分的設計都會踩到這個坑。

## 二、為什麼不是用標準差

先評估過的方案，都不可行或方向錯誤：

**直接用 σ** —— 尺度相依。大立光 EPS 在 134～194、第一金在 1.5～1.9，前者 σ 必然是
後者的百倍，只反映股本結構。連排序都不能用。

**用 CV（σ/μ）** —— 方向是反的。實測 `Spearman(現行分數, CV) = +0.215`，
期望應為負。原因是 CV 把趨勢算進離散度：

| | CV | 趨勢成長率 |
|---|---|---|
| 奇鋐（逐年高速成長）| **70.6%** | +56.4% |
| 統一（五年原地踏步）| **6.5%** | −0.4% |

CV 把「逐年高速成長」判成極不穩定，把「五年停滯」判成極穩定。

**用 σ(Δln EPS)（成長率波動度）** —— 方向正確（Spearman −0.235）但相關性很弱，
因為它與「穩定成長」的語意仍有三個本質差異：對稱（上漲也算波動）、
路徑無關（把五年打亂 σ 不變，但「衰退後恢復」與「連續三年探底」意義完全不同）、
且 N=5 只產生 4 個觀測值。

## 三、候選公式

核心：對 $\ln E_t$ 做時間迴歸，一次取出成長與可信度。

$$\ln E_t = \alpha + \beta t + \varepsilon_t$$

- $g = e^{\beta} - 1$：趨勢年化成長率（五點共同決定，非頭尾 CAGR）
- $R^2$：趨勢解釋力
- $D = \max_j\left(1 - E_j / \max_{k \le j} E_k\right)$：EPS 最大回撤

$$\text{Score} = 2 \times \underbrace{G(g)}_{\text{成長}} \times \underbrace{Q(R^2)\cdot P(D)}_{\text{可信度}}$$

$$G = \mathrm{clip}\!\left(\tfrac{g-3\%}{15\%-3\%}\right),\quad
Q = \mathrm{clip}\!\left(\tfrac{R^2-0.3}{0.8-0.3}\right),\quad
P = \mathrm{clip}\!\left(\tfrac{40\%-D}{40\%-10\%}\right)$$

**設計要點**

- **乘法而非加總**：「穩定成長」是連言。沒有成長則 $G=0$、總分為 0，不論多穩定 ——
  這樣中華電（$g$=1.8%）與南亞（$R^2$=0.85 但 $g$=−55%）都拿 0。
- **$\ln$ 轉換**讓指標尺度無關，且讓「成長」等於趨勢斜率而非離散度 —— 這正是 CV 失敗之處。
- **clip 線性漸變而非階梯**：避免明線懸崖，是穩健性改善 2.7 倍的主因。
- **$P$ 的分子是 $(D_1 - D)$**，方向與另兩者相反，因為回撤愈小愈好。
- **$R^2$ 只能當乘數**，方向必須由 $\beta$ 決定（見問題 3）。
- **任一年 EPS ≤0 → 0 分**。藥華藥 −10.8 → 14.27 是漂亮的轉機股，但「五年穩定成長」
  這個因子本就不該給它分，那是另一個因子該捕捉的事。

## 四、尚未決定（需求方拍板前不要實作進 factors.py）

**1. 金融業是否用較低的成長門檻**
$g_0 = 3\%$ 會判死多數金融股 —— 台灣金控的 EPS 成長天生溫和（永豐金 8.9%、
華南金 10.9% 已算好的）。PRD §8.12 本來就有金融業專屬矩陣，可給一組較低的
$g_0/g_1$。不設的話，金融股在這個因子上會系統性偏低。

**2. 連續分數或分箱**
連續（0.00～2.00）的好處是第二階段權重最佳化有梯度可用、同分打結大減；
代價是失去「5%／12%」那種可對著財報逐格稽核的明線。若要保留可稽核性可分箱成
{0, 0.5, 1, 1.5, 2}，但會吐掉一部分剛拿回來的穩健性。

## 五、怎麼自己試

```bash
python scripts/eps_score.py --in 你的EPS檔.csv --out eps_scored.csv
python scripts/eps_score.py --in 你的EPS檔.csv --out eps_scored.csv \
    --g0 0.05 --g1 0.20 --r0 0.4 --d1 0.5      # 換一組門檻
```

輸入吃長表或寬表（自動判別），欄名以同義字比對，處理千分位、會計括號負數與缺值。
輸出含新舊分數、$g$／$R^2$／回撤、三個 clip 分量，以及每個 0 分的具體原因。

門檻全部是 CLI 參數，不寫死於邏輯（PRD §12），便於第二階段最佳化。
